\# Deogiri College Placement Platform



A web-based college placement management system built with Python and Django. The platform connects students, recruiters, and college administrators through a centralized placement portal.



🌐 \*\*Live Demo:\*\* https://deogiri-college-placement-platform.onrender.com



💻 \*\*GitHub Repository:\*\* https://github.com/Gauravprivate/deogiri-college-placement-platform



\---



\## Project Overview



The Deogiri College Placement Platform is designed to simplify and organize the college placement process. It provides separate portals for students, recruiters, and college administrators.



Students can explore job opportunities, apply for jobs, manage their profiles, and track application statuses. Recruiters can post jobs, view applicants, and update application statuses. College administrators can manage students, recruiters, jobs, and placement activities.



\## Features



\### Student Portal



\* Student login using PRN and password

\* Student dashboard

\* Profile management

\* Browse available job opportunities

\* Apply for jobs

\* Track job application status

\* Resume creation and editing

\* Resume download

\* Application consent and declaration



\### Recruiter Portal



\* Recruiter login

\* Recruiter dashboard

\* Post and manage job openings

\* View applicants

\* Review applicant profiles and resumes

\* Update application statuses

\* Track recruitment activity



\### College Admin Portal



\* Admin login and dashboard

\* Manage student records

\* Manage recruiter accounts

\* Review and manage job postings

\* Manage placement notices

\* Manage interviews and online tests

\* View placement analytics and reports

\* Monitor application progress

\## Local Installation



To run the project locally:



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/Gauravprivate/deogiri-college-placement-platform.git

&#x20;  ```



2\. Navigate to the project directory:



&#x20;  ```bash

&#x20;  cd deogiri-college-placement-platform

&#x20;  ```



3\. Install the dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Apply database migrations:



&#x20;  ```bash

&#x20;  python manage.py migrate

&#x20;  ```



5\. Start the development server:



&#x20;  ```bash

&#x20;  python manage.py runserver

&#x20;  ```



6\. Open the following address in your browser:



&#x20;  ```text

&#x20;  http://127.0.0.1:8000/

&#x20;  ```
